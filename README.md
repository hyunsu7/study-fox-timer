# 🐧 빠로로와 함께하는 공부하루 (Pororo Study Timer)

동물들의 숲(너굴) 테마 공부 앱을 참고해서 만든 **빠로로 테마 공부 타이머** 웹앱입니다.

## 주요 기능

- 📚 **과목별 타이머** : 국어, 영어, 수학 등 과목별로 공부 시간 측정
- ⏱️ **실시간 누적** : 다른 과목으로 전환해도 이전 과목 시간이 자동 저장
- 📷 **오늘의 공부 기록 저장/공유** : 한 장의 카드로 오늘 공부한 내용을 예쁘게 저장하거나 공유
- ✏️ **과목 편집** : 원하는 과목을 추가/삭제/이름 변경
- 💾 **로컬 저장** : 브라우저에 공부 기록이 자동으로 저장됩니다

## 테마

- 기존 너굴(Tom Nook) → **빠로로(🐧)** 캐릭터로 변경
- 시원하고 상쾌한 하늘색/파란색 계열 감성
- 빠로로 특유의 밝고 활기찬 응원 메시지

## 사용 방법

1. 과목을 클릭하면 타이머가 시작됩니다.
2. 다시 클릭하거나 다른 과목을 누르면 현재 과목이 저장되고 전환됩니다.
3. **「오늘의 공부 기록 저장하기」** 버튼을 누르면 예쁜 카드가 생성됩니다.
4. 이미지로 저장하거나 텍스트로 복사해서 SNS/카톡에 공유하세요.

## 실행 방법

그냥 `index.html` 파일을 브라우저로 열면 됩니다.

또는 로컬 서버로 실행:

```bash
npx serve .
# 또는
python -m http.server 8000
```

## 기술 스택

- 순수 HTML + CSS + Vanilla JavaScript
- LocalStorage로 데이터 영속화
- 외부 라이브러리 없음 (가볍고 빠름)
